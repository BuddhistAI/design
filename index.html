BuddhistAI design system 1.0.0

One look for every BuddhistAI site

The homepage, the leaderboard, the knowledge base and the arena all use these colors, fonts, parts and words. Link one CSS file, or copy the tokens into your own app.

Use it in your site Writing rules
Colors

Colors

Cool paper and ink, with three accents that always mean the same thing. Lapis is top performance and links. Saffron is best value and contributing. Green is measured and new leaders. Every color has a dark-mode value; switch your system theme to see it.

Type

Fonts

Bricolage Grotesque for headings and big numbers. Inter for text. JetBrains Mono for commands and IDs. Noto Serif Tibetan for Tibetan.

Heading 2

Heading 3

Body text is 15px Inter with a line height of 1.6. Keep a paragraph under 62 characters wide.

Notes and meta are 13px, muted.

Use it

Add it to a site

Static sites: copy buddhistai.css and the logo files into your site and link them. React or Tailwind: use tokens.js or tailwind.preset.js.

HTML

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,500;12..96,700;12..96,800&family=Inter:wght@400;500;600&family=JetBrains+Mono:wght@400;500&family=Noto+Serif+Tibetan:wght@400&display=swap">
<link rel="stylesheet" href="buddhistai.css">

React + Tailwind

// tailwind.config.js
module.exports = {
  presets: [require('./tailwind.preset.js')],
};
// main.tsx
import './buddhistai.css';
